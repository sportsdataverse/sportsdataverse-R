# Get a situation report on the sportsdataverse

This function gives a quick overview of the versions of R and RStudio as
well as all sportsdataverse packages. It's primarily designed to help
you get a quick idea of what's going on when you're helping someone else
debug a problem.

## Usage

``` r
sportsdataverse_sitrep()
```

## Value

Called for its side effect of printing the report; returns `NULL`
invisibly.
