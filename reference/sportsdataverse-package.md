# sportsdataverse: Easily Install and Load the 'SportsDataverse'

Installs and loads, in a single step, the set of 'sportsdataverse'
sports data packages, which work in harmony because they share common
data representations and 'API' design. Also reports and updates the
installed versions of those packages. Learn more about the
'sportsdataverse' at <https://sportsdataverse.org>.
